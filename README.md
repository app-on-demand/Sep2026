# 우리의 한 시즌

멘토링 팀(멘토 1명, 멘티 3명)의 한 시즌을 회고하고, 그 과정에서 자연스럽게 서로에게 보낼 감사 카드가 만들어지는 작은 페이지입니다.
로그인도 서버도 없습니다. `index.html` 파일 하나가 전부예요.

## 흐름

1. **나는 누구?** 4명 중 선택
2. **타임라인 회고** 프로젝트마다 감정 스티커, 가장 남은 프로젝트와 이유
3. **4Ls 회고** Liked / Learned / Lacked / Longed for
4. **AI 시대의 나** 신뢰도·부담 슬라이더, 시즌 전후의 나 한 단어
5. **리더 회고 (KPT)** Keep / Try 한 줄씩
6. **감사 라운드** 나머지 3명에게 각각 "우리 팀의 ___" 칭호 + 고마웠던 장면 + 한마디
7. **결과** 내 시즌 카드 1장 + 편지 카드 3장 → 이미지 저장 / 링크 복사
8. **편지 받기** 링크를 열면 봉투가 나오고, 탭하면 편지가 펼쳐짐
9. **받은 편지 모으기** 받은 링크를 붙여넣으면 앨범으로 모이고, 앨범도 링크 하나로 공유

편지 내용은 압축되어 URL 안에 들어갑니다. 링크 자체가 편지라서 서버가 필요 없어요.
진행 중인 답변은 브라우저 `localStorage`에 자동 저장됩니다.

## 팀 정보 바꾸기

`index.html` 상단의 `TEAM` 객체만 고치면 됩니다.

```js
const TEAM = {
  season: "2026 멘토링 시즌",
  members: [ { id, name, role, color }, ... ],
  projects: [ { name, leader: "<member id>" }, ... ],   // 시간순
};
```

질문 선택지는 바로 아래 `FOUR_LS`, 칭호는 `TITLES`, 감정 스티커는 `MOODS`에서 수정합니다.

## 실행

로컬에서 파일을 직접 열어도 되지만, 이미지 저장(폰트 포함)이 제대로 되려면 http로 서빙하는 편이 좋습니다.

```bash
npx --yes serve -l 8765 .
```

## 배포

정적 파일 하나이므로 GitHub Pages, Vercel, Netlify 어디든 올리면 됩니다.
링크에 편지 내용이 담기므로, 배포한 주소로 접속해서 링크를 만들어야 팀원이 열 수 있습니다.
